# Raízes do Nordeste

Sistema de pedidos online para a rede de lanchonetes Raízes do Nordeste.

Projeto desenvolvido para a disciplina de Projeto Multidisciplinar — Trilha Front-End (UNINTER, 2026).

## Como rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173/raizes-do-nordeste/`

## Tecnologias

- React 19 + TypeScript
- Vite
- React Router DOM
- Lucide React (ícones)
- CSS puro com variáveis customizadas

## Funcionalidades

- Cardápio com filtro por categoria
- Carrinho de compras com adição/remoção de itens
- Checkout com simulação de pagamento externo (PIX e Cartão)
- Consentimento LGPD obrigatório antes do pagamento
- Programa de fidelidade (pontos por compra)
- Layout responsivo (mobile e desktop)

## Deploy

```bash
npm run deploy
```

Publica automaticamente no GitHub Pages.
